개인정보처리방침

주식 파이프라인2는 소유자 본인만 사용하는 개인용 Google Apps Script 프로젝트입니다.

  • 소유자 본인의 Google Drive·Sheets 파일만 읽고 씁니다.
  • 다른 사람의 개인정보를 수집하지 않습니다.
  • 데이터를 판매하거나 제3자와 공유하지 않습니다. 광고에 쓰지 않습니다.
  • Google 사용자 데이터의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

Privacy Policy

This personal Apps Script project reads and writes only its owner's own Google Drive and Sheets files. It collects no data from anyone else, does not sell or share data, and does not use it for advertising. Use of Google user data follows the Google API Services User Data Policy, including the Limited Use requirements.
